Twin Tides is a polished, highly detailed spot-the-difference puzzle game featuring three rich, hand-crafted vector scenes: **Harbor Sunset**, **Midnight Garden**, and **Morning Bakery**. Compare the side-by-side twin panels to spot subtle changes in color, position, and objects.

## How to Play
- Find **7 differences** in each scene by clicking them on either the left or right panel.
- Correct clicks place a permanent green highlight ring on both panels and award points.
- Incorrect clicks incur a brief time penalty and reduce your max possible stars.
- Press **H** or click the Hint button if you get stuck.
- Complete all 3 scenes with high accuracy to earn 3 stars on each level!



## Run it
Open `game/index.html` in a desktop browser, or serve the `game/` folder with any static server. No build step or network connection required.
